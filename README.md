# Мини-апп для бота с заданиями

## Что изменилось
- `webapp.go` — новый файл: HTTP-сервер, отдаёт мини-апп (`miniapp/*`) и JSON API
  (`GET/POST /api/homework`, `DELETE /api/homework/{id}`), проверяет подпись
  `initData` от Telegram, задаёт кнопку меню бота.
- `main.go` — точечные правки: читает `MINI_APP_URL` и `PORT`, поднимает веб-сервер
  параллельно с ботом, `/start` теперь присылает кнопку «Открыть список заданий».
- `miniapp/` — сама мини-аппа (HTML/CSS/JS, без сборки, ванильный JS), подстраивается
  под тему Telegram.
- Новых зависимостей нет — использована только стандартная библиотека Go, `go.mod`
  трогать не нужно.
- Текстовые команды (добавление сообщением, `/list`, `/delete`) оставлены как есть —
  ими по-прежнему можно пользоваться, мини-апп добавлен параллельно.
- Схему БД не менял: мини-апп использует те же таблицы `homework`/`reminder_log`.
  `chat_id` в БД трактуется как Telegram user id — это верно, пока бот общается с
  пользователями только в личных чатах (как сейчас).

## Переменные окружения
| Переменная | Обязательна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | как раньше |
| `DATABASE_URL` | да | как раньше |
| `BOT_TIMEZONE` | нет | как раньше |
| `MINI_APP_URL` | нет* | публичный HTTPS-адрес мини-аппа, например `https://homework.example.com` |
| `PORT` | нет | порт для веб-сервера, по умолчанию `8080` |

*Без `MINI_APP_URL` бот продолжит работать как раньше (только текстом), просто без
кнопки. Задайте её, когда задеплоите и получите постоянный HTTPS-домен.

## Деплой
1. Разверните бинарник так, чтобы порт `PORT` был доступен снаружи по HTTPS
   (например, за Caddy/Nginx с TLS, или на платформе, которая сама даёт HTTPS-домен).
   Telegram Mini App **обязательно** требует HTTPS.
2. Пропишите `MINI_APP_URL=https://ваш-домен` и перезапустите бота — при старте он
   сам вызовет `setChatMenuButton`, домен в BotFather дополнительно регистрировать
   не нужно (это требуется только для прямых ссылок вида `t.me/bot?startapp=...`,
   которые здесь не используются).
3. Откройте бота в Telegram, нажмите `/start` или кнопку меню — откроется мини-апп.

## Известные ограничения / что стоит проверить
- Я не смог собрать проект в этой песочнице (нет Go-тулчейна и сети) — код проверен
  вручную построчно и синтаксис JS проверен через `node --check`, но перед деплоем
  прогоните `go build ./...` у себя.
- Не хватало файлов `migrations/*.sql` и `go.mod` — они не были загружены, поэтому
  я их не трогал. Схема БД в API-хендлерах выведена из тех же SQL-запросов, что уже
  были в `main.go`, так что расхождений быть не должно.
- Мини-апп не дублирует напоминания — они по-прежнему шлются ботом в фоне
  (`reminderLoop`), это не зависит от того, открыт мини-апп или нет.
